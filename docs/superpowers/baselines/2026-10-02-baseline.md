# Phase 0 skill baselines

<!-- markdownlint-disable MD024 -->

Recorded 2026-10-02. This is the baseline for the claude-md-optimizer
rework: what the original skill advises, scored against four rubrics. Later
phases re-run the same scenarios and compare.

## What was run

- Skill under test: `claude-md-optimizer/` as on `main` at `e913eb3`. The
  skill directory is unchanged through the Phase 0 branch head `de603d6`.
- Scenarios and fixtures: `tests/scenarios/` and `tests/fixtures/` on branch
  `chore/baseline-fixtures`.
- Model: Sonnet, for all fifteen runs and for the scorer. Every later re-run
  must use the same model.
- Runs: 5 scenarios, 3 repetitions each, each a fresh general-purpose
  subagent given only a setup line and the scenario's prompt. The fifth
  scenario, audit-clean-file, was added and run after the first twelve.
- Scoring: one separate scorer subagent applied the README scoring rules
  (PASS or FAIL per rubric line, quote as evidence). The controller
  spot-checked the FAIL verdicts, the surprising PASS verdicts, and the
  disputed lines against the raw transcripts.

## Deviations from the README protocol, and caveats

- The setup line carried three additions, now documented in the README
  under "Setup line used": a `HOME` override for the script, an
  advice-only instruction, and an output file for the reply.
- Enforce-with-hooks rep 1 and audit-clean-file rep 1: the sandbox blocked
  the `HOME` override, so the script scanned the real `~/.claude` of the
  person running the baseline. The other thirteen runs report an isolated
  scan.
- Every run inherited the runner's global Claude Code instructions. Five
  runs (enforce-with-hooks rep 3, audit-clean-file rep 3 and all three
  split-with-imports reps) address the user by name. This is not a
  clean-room baseline, and it may
  flatter the scenarios about hooks and imports, which that setup already
  discusses.
- The audit-derivable-tree rubric line N3 was found defective after scoring.
  As first written it also failed the correct answer (keeping a decision
  the code cannot show, such as the production database). It was reworded
  in commit `7765b5b` and the three audit runs were re-scored. Both
  verdicts are kept below.

## Results

The detailed per-line verdicts follow. In short:

- explain-context-cost fails in all three runs. Each repeats the skill's own
  claims that the file is sent with every request, that this adds up to
  about 168,000 tokens over 30 turns, and that 150 lines is the recommended
  maximum. This is the clear signal for the rework.
- audit-derivable-tree passes in two of three runs (none under the
  original N3). Rep 2 fails because it advises keeping a one-line summary
  of where routes live, a rewritten layout description.
- split-with-imports passes two of three runs. Rep 2 proposes splitting
  `docs/conventions.md` into new topic files.
- enforce-with-hooks passes all three runs.
- audit-clean-file fails all three runs, though mildly. No run advises
  adding a section, which was the hypothesis. Rep 1 says to extract
  reference material if the file grows past about 80 lines, rep 2 suggests
  adding a project summary line, and rep 3 offers an optional reword with
  no functional reason. All three are hedged, optional suggestions made to
  a file that needs nothing.

## What these baselines can and cannot show

- Two scenarios clearly separate the current skill from Anthropic's
  current guidance. Explain-context-cost is the strong one: the failures
  are the skill's own wrong claims. Audit-clean-file is weaker: its
  failures are hedged suggestions, and a couple of its rubric lines
  (A2, N5) still need a judgement call at the margins.
- The other three scenarios already pass most or all runs on the original
  skill. They are regression guards: they show the rework did not make the
  advice worse, not that it made it better.
- The hypothesis that the original skill would push missing sections onto
  a clean file was not borne out on Sonnet with this setup. That does not
  show the scoring is harmless; the script's output still rewards
  structure, and the model overrode it in these runs.
